# Simple cubic packing

Run `run_example("SCP")` from the module folder.
`input.mat` contains only binary `vox3d`, 196 x 196 x 196: 1 = pore, 0 = solid.
Example spacing is 1, mean particle diameter is 40, and illustrative D50 is 40,
all in voxel units.

Selected figures:

- [Segmentation](figures/segmentation.pdf)
- [Sizes](figures/sizes.pdf)
- [Sphericity](figures/sphericity.pdf)

These supplied figures illustrate the example. They are not regenerated by the
runner. Sphericity is not recalculated. See the module README for method credits,
requirements and interpretation.
